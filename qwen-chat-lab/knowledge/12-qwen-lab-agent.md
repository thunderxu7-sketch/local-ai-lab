# Qwen Lab · 对话模式与 Agent

本文依据项目 README 的对话模式和 Agent 章节整理，并与 app/api/chat/route.ts、lib/agent.ts 核对。

## 三种对话模式

Qwen Lab 的普通对话会带上本次会话中已完成的聊天历史，适合连续追问，也可调用计算器。知识库问答每次只检索当前问题，Agent 每次只处理当前任务；这两种模式都不携带前一任务的聊天历史，追问必须写清主题。它们的消息显示在同一网页，但 RAG 和 Agent 的回答不加入普通聊天的上下文。模型不会自动跨请求记住用户。

## Agent 工具与调用限额

Qwen Lab 的 Agent 有 search_knowledge（检索本地知识库）和 calculate（两个数字的加减乘除）两个工具。每个任务最多 3 轮工具执行、4 次工具调用，其中知识库检索最多 2 次，每次最多返回 2 个原文片段。重复片段沿用本轮引用编号。模型决定是否调用工具及顺序，依赖上一步结果时应等待返回后再构造下一次调用。

## Agent 的执行反馈

Qwen Lab 会校验工具参数并执行本地函数，把结果交回模型；不会执行模型提供的任意代码。工具卡片展示真实参数、结果、轮次与耗时。遇到明确的数值等式却没有成功的计算器结果时，应用最多要求模型补做一次核验，仍未完成时会报错。这不是完整的数学解析或正确性验证。工具错误也会反馈给模型，停止生成会取消后续请求。
