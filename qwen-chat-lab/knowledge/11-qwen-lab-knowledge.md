# Qwen Lab · 知识库与检索

本文依据项目 README 的知识库章节整理，并与 lib/knowledge.ts、lib/vector-index.ts 核对。这里描述 Qwen Lab 本身的能力，不是“青竹笔记”的导入规则。

## 文档格式与容量

Qwen Lab 从项目 knowledge/ 目录读取 UTF-8 编码的普通 .md 文件，不读取子文件夹或符号链接。建议用 Markdown 标题划分主题。上限为 40 份文件、单文件 128 KB、全部文件共 1 MB、最多 3000 个片段；容量采用十进制字节，即 128000 与 1000000 字节。超出限制会报错，不会悄悄截断。

## 文档变化与索引更新

Qwen Lab 每次检索都会重新读取文档并校验本地向量索引。新增或修改的片段生成向量，未变化的向量直接复用，删除的片段不再参与检索。改完资料无需重启服务。知识库页面的“刷新文档”可查看资料；“更新向量索引”可提前处理变化。完整索引构建成功后才替换磁盘文件，失败不会覆盖旧索引。

## RAG 分段与召回

Qwen Lab 按 Markdown 标题分段，每段最多 650 字符，长段之间重叠 100 字符。知识库问答使用 qwen3-embedding:0.6b 的 1024 维单位向量，以余弦相似度排序；低于 0.45 的片段被过滤，最多向回答模型提供 3 个原文片段。相似度用于排序，不是答案正确率。没有足够相关的片段时，知识库问答直接提示资料不足。

## 引用与历史资料

Qwen Lab 的回答可标注 [1] 等引用，点击编号会展开对应文件、标题、行号和原文。运行记录保存回答当时的原文快照，因此后来修改文档不会改变旧记录。引用编号存在，只说明可以定位原文，不保证回答受到原文支持；仍需对照内容核验。
